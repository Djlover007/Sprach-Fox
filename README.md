# Sprach Fox

Sprechen, übersetzen und lernen wie in der Schule. Design by Mr.Fox.

- **Übersetzen:** Satz sprechen oder tippen, in mehrere Sprachen gleichzeitig übersetzen, anhören (auch langsam), Wörter antippen, nachsprechen mit Aussprache-Bewertung
- **Vokabeln:** gemerkte Sätze und Wörter mit Lernstand
- **Üben:** Karteikasten mit Wiederholung, Modi Übersetzen, Hören und Sprechen, Zeugnis mit Note am Ende
- **Lehrer:** fertige Lektionen und ein Lehrer-Chat (Claude-Schlüssel nötig)

Die APK baut GitHub Actions bei jedem Push auf `main` und hängt sie an ein Release. Updates kommen danach direkt über die App.
